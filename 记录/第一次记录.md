## 学习神经网络的代码格式
[Pytorch说明文档](https://docs.pytorch.org/docs/)
```
class DQN(nn.Module):
    def __init__(self,n_observations,n_actions):
        super(DQN,self).__init__()
        self.layer1 =nn.Linear(n_observations,128)
        self.layer2 =nn.Linear(128,128)
        self.layer3 =nn.Linear(128,n_actions)

    def forward(self,x):
        x=F.relu(self.layer1(x))
        x=F.relu(self.layer2(x))
        return self.layer3(x)
```
>- 类似这样的格式，首先要继承`nn.Module`这个父类
>- 初始话需要传入两个参数，第一个是输入特征数，第二个是输出特征数
>  - 里面的中间层要严格的以这层输入为上一层输出，一一对应下来 
>  - 最后一层的输出是输出的特征数
>- 定义每一层的激活函数

> 为什么最后一层没有激活函数？  
> Q值是动作的期望总回报，可以是任意实数
> 如果加了 Sigmoid（输出 0-1）或 Tanh（输出 - 1 到 1），会强行限制 Q 值的范围，导致网络无法正确学习  
> 只有在 **策略梯度 (Policy Gradient)** 算法中，最后一层才会加 Softmax 输出动作概率

## replay memory 实现

class ReplayMemory:
    def __init__(self, capacity):
        self.memory = deque([],maxlen=capacity)
        self.capacity = capacity
    def push(self,*args):
        self.memory.append(Transition(*args))
    def sample(self,batch_size):
        return random.sample(self.memory,batch_size)
    def __len__(self):
        return len(self.memory)
```

```
import gymnasium as gym
env = gym.make("CartPole-v1", render_mode="human")
observation, info = env.reset()
print(f"Starting observation: {observation}")
episode_over = False
total_reward = 0
while not episode_over:
    action = env.action_space.sample()  
    observation, reward, terminated, truncated, info = env.step(action)
    total_reward += reward
    episode_over = terminated or truncated
print(f"Episode finished! Total reward: {total_reward}")
env.close()
